# AlgoScope — Data Structure Playground

An interactive, browser-only visualizer for a stack, queue, and singly linked list.

## Try it

Open `index.html` in a browser. Choose a structure, enter a value, then use Push/Enqueue/Append, Pop/Dequeue/Remove first, Peek, and Reset. The diagram and recent operation list update as you work. The app displays the expected time complexity for each operation.

## Concepts

- Stack: last in, first out.
- Queue: first in, first out.
- Singly linked list: nodes connect to the next node; this simple implementation appends by walking from the head, so append is O(n).

No values are uploaded or persisted. This is an educational model, not a production data structure library.
